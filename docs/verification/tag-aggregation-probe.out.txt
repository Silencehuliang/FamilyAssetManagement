=== [Q5] 路径枚举前缀 LIKE 的索引命中 ===

  [A] 表上仅普通(BINARY)索引，case_sensitive_like=OFF（SQLite 默认）
  --- A1 字面量 pattern
      SELECT id,name FROM tag WHERE path LIKE '/1/%'
      SCAN tag
  --- A2 绑定参数 pattern
      SELECT id,name FROM tag WHERE path LIKE ?
      SCAN tag

  [A'] 表上仅普通索引，case_sensitive_like=ON
  --- A1' 字面量 pattern
      SELECT id,name FROM tag WHERE path LIKE '/1/%'
      SEARCH tag USING INDEX idx_path_bin (path>? AND path<?)
  --- A2' 绑定参数 pattern
      SELECT id,name FROM tag WHERE path LIKE ?
      SEARCH tag USING INDEX idx_path_bin (path>? AND path<?)

  [B] 表上仅 NOCASE 索引，case_sensitive_like=OFF（默认）
  --- B1 字面量 pattern
      SELECT id,name FROM tag WHERE path LIKE '/1/%'
      SEARCH tag USING INDEX idx_path_nocase (path>? AND path<?)
  --- B2 绑定参数 pattern
      SELECT id,name FROM tag WHERE path LIKE ?
      SEARCH tag USING INDEX idx_path_nocase (path>? AND path<?)

  结论：默认配置 + 普通索引 → SCAN（全表）；须 NOCASE 索引或开 pragma 才命中。
        两级约束下改用 parent_id 自连接，完全绕开此陷阱。
