[1] 除权除息日：昨收取自当日 feed 还是本地历史，差出一条假暴跌
==============================================================================
  每股现金红利（税前）  = 28.02423 元 = 2802.423 分
  除权(息)参考价        = 前收盘 1,212.10 − 现金红利 = 118407.577 分 → 按分取整 = 118408 分 = 1,184.08 元
  实测 feed 该日昨收     = 1,184.08 元
  → 取整后与实测完全一致（差 0 分）；复权因子恰等于每股红利

  除权除息日 2026-06-26 的「当日收益（每股）」：
    路径 A（昨收取自当日 feed，即除权参考价） = 1,168.63 − 1,184.08 = -15.45 元/股   ✔ 真实
    路径 B（昨收取自本地前一日收盘）         = 1,168.63 − 1,212.10 = -43.47 元/股   ✘ 假暴跌
    对应涨跌幅：路径 A -1.30% ／ 路径 B -3.59%
    两条路径之差 = 28.02 元/股 = 每股现金红利（本已落袋的那部分，被误算成亏损）

[3] 持仓变动当日：按当日生效版本计算 ⇒ 存在不可消除的误差（须显式标注）
==============================================================================
  系统不知道成交时点与成交价（不管理买卖），因此变动当日只能整日按新数量算。
  误差上界 = |当日数量变动| × |当日每股涨跌额|

  场景             变动前   变动后   每股涨跌 系统当日收益             真实值区间     误差上界
  加仓 1000 股       1000     2000       0.50     1,000.00      500.00 ~ 1,000.00       500.00
  减仓 1000 股       2000     1000      -0.50      -500.00    -1,000.00 ~ -500.00       500.00

  → 加仓且当日上涨时系统高估；加仓且当日下跌时系统低估。方向随涨跌与增减反向。
  → 该误差**不可消除**（无成交时点信息），只能对含持仓变动的交易日打显式标记。

[4] 区间收益的垫消：Σ当日收益 = 期末市值 − 期初市值；区间收益率 = Σ ÷ 期初市值
==============================================================================
  区间 2026-04-02 ~ 2026-04-08，持仓恒为 2000 股

  日期         星期       昨收       收盘     当日收益
  2026-04-02   四        10.50      10.60       200.00
  2026-04-03   五        10.60      10.42      -360.00
  2026-04-07   二        10.42      10.80       760.00
  2026-04-08   三        10.80      10.75      -100.00

  Σ当日收益            = 500.00 元
  期末市值 − 期初市值   = 21,500.00 − 21,000.00 = 500.00 元   ✔ 恒等
  区间收益率           = 500.00 ÷ 21,000.00 = 2.38%

[5] 多成员汇总：金额相加；收益率必须按分母加权（简单平均会失真）
==============================================================================
  成员           持仓成本     累计浮动盈亏   累计收益率
  成员 A       100,000.00        10,000.00       10.00%
  成员 B        10,000.00        -1,000.00      -10.00%
  合计         110,000.00         9,000.00

  简单平均收益率 = 0.00%
  加权收益率     = 9,000.00 ÷ 110,000.00 = 8.18%   ✔ 采用
  两者相差       = 8.18 个百分点 —— 简单平均会被小账户的高波动率带偏

[6] 未交易金额不进收益率分母（否则是「现金不产出却被算作本金」的自相矛盾）
==============================================================================
  持仓成本合计   = 110,000.00 元
  未交易金额合计 = 50,000.00 元

  口径 A（推荐）：分母 = 持仓成本合计
      累计收益率 = 9,000.00 ÷ 110,000.00 = 8.18%
  口径 B：分母 = 持仓成本合计 + 未交易金额
      累计收益率 = 9,000.00 ÷ 160,000.00 = 5.62%

  → 现金不产生收益，分子里没有它的贡献；把它放进分母只是稀释。
  → 未交易金额的角色只有两个：构成「账户总资产」、展示仓位。

[8] 未交易金额不版本化 ⇒ 历史「账户总资产」是两个时点混算，只能作当前值
==============================================================================
  历史日 2026-03-02：数量 1500 股 × 当日收盘 12.00 元 = 市值 18,000.00 元（历史值）
  未交易金额：      50,000.00 元（**今日值**，无版本）
  「总资产」若如此相加 = 68,000.00 元 —— 市值是 2026-03-02 的，现金却是今天的。
  → 结论：账户总资产**只作当前值展示，不画历史曲线**；历史曲线一律画持仓收益。

结论
==============================================================================
1. 除权除息日的「昨收」必须取自当日行情 feed：交易所已把它置为除权(息)参考价，
   `(今收−昨收)` 因此天然免疫分红/送转跳空。若用本地前收，会凭空造出 28.02 元/股的假暴跌。
2. 持仓版本 `(成员, 代码, 生效日) → (数量, 成本价)` 用一条 SQL 按日取数，走主键索引；
   允许「中间插入」，补录历史变更不改动既有行 —— 这是版本化相对当前基线的核心优势。
3. 持仓变动当日的收益误差上界 = |数量变动| × |当日每股涨跌额|，不可消除，须显式标注。
4. 区间收益满足垫消恒等式（Σ当日收益 = 期末市值 − 期初市值），区间收益率为其 ÷ 期初市值。
5. 多成员金额相加、收益率加权；未交易金额不进分母；清仓版本截断未来不改写过去。
