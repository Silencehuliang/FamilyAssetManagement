# 数据按月分文件存储,记录级冲突后写胜出

Status: accepted

账本数据要人类可读、可增量同步、可手工修复。我们决定:账本仓库内按集合分文件——支出按自然月一个 JSON 文件,成员/分类/标签/预算/周期规则等元数据各一个 JSON 文件;同步以文件为增量单位(按内容哈希对比),记录级冲突采用记录 `updatedAt` 后写胜出(LWW)。

## Considered Options

- **单一大 JSON 文件**:实现简单,但每次同步全量传输,冲突粒度粗到两人同月记账即互踩。
- **逐记录远端数据库**:冲突处理精细,但放弃纯文本可读性与 git 历史回滚,违背 ADR-0001。
- **按月分文件 + LWW(选定)**:家庭场景同人同月并发编辑罕见,LWW 足够;月文件天然对齐报表与归档习惯。

## Consequences

- 跨月报表需聚合多个月文件,在客户端内存完成。
- 文件结构一旦有设备落账即难变更,后续调整需带数据迁移。
