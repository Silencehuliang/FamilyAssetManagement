# 只记支出:不做收入、资产账户与余额

Status: accepted

项目仓库名为 FamilyAssetManagement,但实际需求收敛为「家庭支出记账」。我们明确 v1 领域模型只含支出:不记收入、不做资产账户、不算余额、不做转账与多币种。统计报表相应聚焦支出趋势、分类占比、预算执行与成员对比。

## Considered Options

- **含负债/资产账户与净资产视图**:契合仓库字面含义,但用户明确表示只需要记录支出,带着资产模型徒增录入与同步复杂度。
- **仅支出(选定)**:录入路径最短,符合家庭记账真实使用频率。

## Consequences

- 仓库/产品名与功能范围不完全对应,以本 ADR 为准。
- 数据模型保持单一正数金额与单一币种字段,为未来扩展收入/资产留缝,但 v1 不建 UI。
