# A 股除权除息与成本价口径事实核实（家庭财务管理系统 · 股票子系统）

> 检索日期：2026-09-15 ｜ 调研人：研究助理（CodeBuddy）
> 目的：为「每日股票账户收益」的口径裁决（口径甲「当日浮动盈亏」=(今收−昨收)×数量；口径乙「累计浮动盈亏」=(今收−成本价)×数量）核实一手事实。
> 系统约束：2 人自用，部署于 Cloudflare 免费套餐；股票子系统**不管理买卖、无成交流水、无手续费数据、无已实现盈亏**；成员手工填写「成本价 + 持仓数量」与「未交易金额」；行情链路主腾讯 `qt.gtimg.cn` → 备新浪 `hq.sinajs.cn` → 东财 `push2his` 历史回填，每日 CST 15:30 抓一次。
> 口径原则：**只认一手来源**（上交所 sse.com.cn / 深交所 szse.cn 官方规则与公告、券商官方帮助文档、交易所/数据商官方接口说明）；二手博客与自媒体复述一律降级标注。

## 1. 除权除息日的「昨收」到底是什么（最关键）

### 1.1 结论

**在除权除息日，行情源返回的「昨收（前收盘）」= 交易所公布的除权（息）参考价（已调整价，即选项 (a)），而不是除权日前一日的原始未调整收盘价（选项 (b)）。该日的涨跌幅也以这个除权（息）参考价为基准计算。沪、深两所口径一致。**

### 1.2 一手依据

**上交所《上海证券交易所交易规则（2026 年修订）》**「第三节 除权与除息」（来源：<https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/c_20260424_10816492.shtml>，检索 2026-09-15）：

> **4.3.2** 除权(息)参考价格的计算公式为：除权(息)参考价格=[(前收盘价格-现金红利)+配股价格×流通股份变动比例]/(1+流通股份变动比例)。……**除权(息)日即时行情中显示的该证券的前收盘价为除权(息)参考价。**
>
> **4.3.3** 除权(息)日证券买卖，按除权(息)参考价格作为计算涨跌幅度的基准，本所另有规定的除外。

**深交所《深圳证券交易所交易规则（2026 年修订）》**「第四节 除权与除息」（来源：<https://docs.static.szse.cn/www/lawrules/rule/stock/trade/W020260424690713155663.pdf>，检索 2026-09-15）：

> **4.4.2** 除权(息)参考价计算公式为：除权(息)参考价=〔(前收盘价-现金红利)+配股价格×股份变动比例〕÷(1+股份变动比例)……
>
> **4.4.3** 除权(息)日证券买卖，按除权(息)参考价作为计算涨跌幅度的基准，本所另有规定的除外。

### 1.3 对「(今收 − 昨收)」公式的影响

- **若「昨收」取自实时行情 feed**（腾讯/新浪/东财实时，均源自交易所即时行情）：除权除息日的「昨收」已被交易所置为除权参考价，因此 `(今收 − 昨收)` 计算的是**真实的当日开收盘波动**，天然吸收（免疫）了分红/送转造成的价格跳空——**本票结论的基石**。
- **若「昨收」取自系统自有历史**（例如用前一日未复权收盘价推算）：则会得到原始未调整前收，在除权日出现一条虚假的「暴跌」跳空，污染口径甲。
- 两交易所规则一致，无需分市场特殊处理。**[官方明确]**

## 2. A 股券商「成本价」的通行口径

### 2.1 一手依据（券商官方帮助文档）

**兴业证券官方帮助《成本价介绍》**（来源：<https://www.xyzq.com.cn/xysec/info/article/21915206>，检索 2026-09-15）明确列出四种成本价及算法。以下为原文转录：**[官方明确]**

| 口径 | 精确含义 | 计算公式 | 依赖的数据 |
|------|----------|----------|------------|
| **买入均价** | 不含历史买入费用，不考虑卖出费用，纯成交价平均数；买卖成交时此价不变 | `(发生前数量×前买入均价 + 本次成交金额) ÷ 发生后数量` | 仅各次**买入成交价与数量**（总成交金额÷总数量） |
| **持仓成本（持仓成本价）** | 揭示总体成本价位，含历史买入费用，不含卖出费用；买入成交变、卖出成交不变 | `(累计买入金额 + 回报买入金额) ÷ (累计买入数量 + 回报买入数量)`；无成交简化成 `累计买入金额 ÷ 累计买入数量` | **累计买入金额（含买入费用）**、累计买入数量 |
| **摊薄成本** | 考虑实时买卖，白天买卖均影响成本；与保本价区别是不计卖出费用 | `[(累计买入金额+回报买入金额 − 累计卖出金额 − 回报卖出金额] ÷ (累计买入数量+回报买入数量 − 累计卖出数量 − 回报卖出数量)` | **完整成交流水（买卖金额+数量）+ 已实现盈亏** |
| **保本价** | 按此价卖出才整体保本，含买卖双向费用，白天有成交即变 | 由 `累计买入金额 = 保本价×当前数量 + 累计卖出金额 − 卖出费用` 反推 | **买入金额（含费）+ 卖出金额 + 卖出费用（佣金/印花税/过户费）** |

> 互证（非官方，仅作一致性参考）：叩富网、和讯、希财、百度百科等社区对「买入均价=总买入成交额÷总买入量」「保本价=(买入总金额+买入总费用+卖出总费用)÷股数」的描述与上述官方口径一致。**[社区经验]**

### 2.2 在本系统（无流水、无费用）下哪些口径根本无法推导

| 口径 | 能否推导 | 原因 |
|------|----------|------|
| 摊薄成本 | **不能** | 必须掌握完整买卖成交流水与已实现盈亏，系统完全没有 |
| 保本价 | **不能** | 必须掌握卖出费用（佣金/印花税/过户费），系统完全没有 |
| 持仓成本（含费） | **不能精确推导** | 需要买入费用；若忽略费用可近似，但不等于券商显示值 |
| 买入均价（纯价） | **不能反推** | 需要各次买入价与数量；成员只填一个「当前成本价」单一值，历史分布已丢失 |

**结论**：成员手工填写的「成本价」是一个**不可分解的单一快照值**，最接近「持仓成本 / 摊薄成本的某一时刻快照」，但既无法用标准券商口径反推，也无法派生出保本价或摊薄序列。系统只能把它当作可信单值使用。**[官方明确]** + **[社区经验]**

## 3. 免费行情源是否提供「分红送配 / 除权除息」事件数据

### 3.1 东方财富免 key 分红送配接口 —— 有，实测可用

**接口**：`https://datacenter-web.eastmoney.com/api/data/v1/get?reportName=RPT_SHAREBONUS_DET&columns=ALL&filter=(SECURITY_CODE="600519")`（无需 token / key）。**[官方明确·实测]**

**实测返回片段（2026-09-15，贵州茅台 600519）**：
```json
{"SECUCODE":"600519.SH","SECURITY_NAME_ABBR":"贵州茅台",
 "PRETAX_BONUS_RMB":280.2423,
 "EQUITY_RECORD_DATE":"2026-06-25 00:00:00",
 "EX_DIVIDEND_DATE":"2026-06-26 00:00:00",
 "IMPL_PLAN_PROFILE":"10派280.2423元(含税)"}
```
→ 含 `EX_DIVIDEND_DATE`（除权除息日）、`EQUITY_RECORD_DATE`（股权登记日）、分红比例等字段，足以让系统**零成本自动判定某只股票今天是否处于除权除息日**。

### 3.2 push2his `fqt=1` 与 `fqt=0` 差异是否隐含复权因子 —— 是，实测可反推

样本：贵州茅台 600519，除权除息日 **2026-06-26**（每股分红 280.2423÷10 = **28.02423 元**）。**（实测经 WebFetch 取数，2026-09-15）**

| 日期 | fqt=0（不复权）收盘 | fqt=1（前复权）收盘 | 两者差 |
|------|--------------------|--------------------|--------|
| 2026-06-24 | 1207.68 | 1179.66 | **28.02** |
| 2026-06-25 | 1212.10 | 1184.08 | **28.02** |
| 2026-06-26（除权日） | 1168.63 | 1168.63 | 0 |
| 2026-06-29 | 1194.96 | 1194.96 | 0 |
| 2026-06-30 | 1185.49 | 1185.49 | 0 |

观察：
- **除权日及之后**：`fqt=1 == fqt=0`（前复权以最新价为锚，不调整近期价格）。
- **除权日之前**：`fqt=1` 比 `fqt=0` 低出的金额 ≈ **28.02 元 = 每股分红**，即累计复权因子。

→ 前/不复权收盘的逐日差额**隐含了复权因子，可反推除权事件与每股分红额**。**[官方明确·实测]**

### 3.3 腾讯 / 新浪实时返回有无除权除息字段 —— 无显式标志

依据既有调研 `a-share-quote-sources.md` 字段清单（新浪逗号分隔 **2=昨收、3=最新价**；腾讯 `~` 分隔 **3=最新价、4=昨收**）：两个实时 feed 的字段中**均不含任何除权除息标志位 / 事件代码**（如「是否除权」「分红比例」等字段不存在）。系统只能从「昨收已被置为除权参考价」这一副作用间接感知，feed 本身不显式声明。**[官方间接]**（基于官方 feed 字段结构）+ **[社区经验]**（字段布局由社区梳理）

### 3.4 结论：系统能否零成本自动得知「某只股票今天除权除息」

**能，且建议走数据接口而非依赖实时 feed：**
1. 用 **东财免 key 分红接口**（`RPT_SHAREBONUS_DET`）一次性/定期拉取持仓股的 `EX_DIVIDEND_DATE`，在每日 Cron 中本地比对「今日 == 股权登记日次一交易日」即可自动判定；
2. 即使不调该接口，实时行情当日的「昨收」已被交易所自动置为除权参考价，口径甲无需额外处理即不跳空——但这只是隐式副作用，不宜作为「判定除权日」的可靠信号。

**[官方明确·实测]**（接口可用）+ **[官方间接]**（实时 feed 无显式标志）

## 5. 对设计的影响（仅事实与其约束，不含完整方案）

1. **口径甲的「昨收」必须取自实时行情 feed，不得从本地历史推算。** 交易所已在除权除息日把「昨收」置为除权参考价、涨跌幅也以此为基准，故 `(今收−昨收)×数量` 天然免疫分红/送转跳空；若用系统自有未复权历史作「昨收」则会出现虚假暴跌。**[官方明确]**
2. **口径乙完全不受除权除息影响（仅「今收」一个变量），但代价是依赖一个不可分解的手工「成本价」快照。** 系统无流水、无费用，既无法校验也无法复算该值，只能作为可信单值录入，且无法派生保本价/摊薄序列。**[官方明确]** + **[社区经验]**
3. **系统可零成本自动感知除权除息**：用东财免 key 分红接口 `RPT_SHAREBONUS_DET` 取 `EX_DIVIDEND_DATE` 本地比对即可，不必依赖实时 feed 的隐式信号；口径甲在该日无需特殊分支。**[官方明确·实测]**
4. **历史回填必须固定单一复权口径。** `fqt=1` 前复权使除权日价格连续、但历史锚点被改写；`fqt=0` 不复权在除权日出现真实缺口、会污染「昨收」推算。推荐：实时 feed 取昨收用于口径甲 + 前复权仅用于走势展示，二者不可混用为同一「昨收」来源。**[官方明确·实测]**
5. **保本价 / 摊薄成本在本系统不可得。** 二者分别依赖卖出费用与完整成交流水，2 人系统若不做费用/流水录入则应只保留「成本价×数量」单一浮动盈亏，不承诺保本价或累计摊薄。**[官方明确]**
